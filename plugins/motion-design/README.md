# motion-design

Fifteen skills that make Claude a careful motion engineer for the web: GSAP (core, timelines, ScrollTrigger, plugins, React),
Motion for React, CSS micro-interactions, SVG drawing and morphing, Three.js and React Three Fiber, GLSL shaders, Apple-style
fluid interfaces, performance debugging, an animation review bar, and `web-motion-studio`, a screenshot, critique and fix loop
driven by Playwright. Skills load only when a task matches their description. See `NOTICE.md` for provenance and licenses.
